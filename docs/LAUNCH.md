# Launch readiness — iOS & iPadOS

Status toward App Store submission. Updated as work lands.

## In the repo (done)

- [x] Universal app: `TARGETED_DEVICE_FAMILY 1,2`; iPhone portrait, iPad all
      orientations + multitasking/multiple scenes
- [x] iPad-adaptive layouts: centered reading column for thread/Today,
      two-up magazine grid for Projects, constellation composes itself for
      the live viewport (rotation/split-view safe)
- [x] App icon (1024 universal, generated by `scripts/make_icon.py` — the
      candlelight orb in ink)
- [x] Privacy manifest (`PrivacyInfo.xcprivacy`): no tracking, no collected
      data, required-reason APIs declared (UserDefaults, file timestamps,
      disk space)
- [x] Export compliance: `ITSAppUsesNonExemptEncryption = NO` baked into
      Info.plist (no per-build compliance questions)
- [x] Accessibility: Reduce Motion honored across all living surfaces
      (orb, glass shimmer, film grain freeze to calm static light)
- [x] Privacy story in-app (the "nothing leaves this device" receipt)
- [x] CI: every pull request and push to `main` builds and tests on a
      macOS runner; logs and crash reports are uploaded as artifacts
- [x] Test suite over the agent logic (date parsing, ToolBox, intent
      router, graph layout, streaming clock)
- [x] Store hardening: Application Support created before SwiftData opens;
      graceful in-memory fallback instead of launch crash

## Needs a human + an Apple Developer account

1. **Membership & identity** — Apple Developer Program ($99/yr). Set
   `DEVELOPMENT_TEAM` in `project.yml`; register the bundle ID (rename
   `com.pocketbrains.app` to a domain you own if needed — one line in
   `project.yml`).
2. **Name check** — confirm "PocketBrains" is free in App Store Connect;
   the display name lives in `project.yml` if it must change.
3. **Device verification pass** — run `docs/VERIFICATION.md`'s checklist on
   real hardware, especially the Foundation Models path (needs an Apple
   Intelligence-capable device; simulator exercises the fallback brain).
4. **TestFlight** — archive in Xcode (Product → Archive → Distribute),
   internal testing first; the app needs zero server setup.
5. **App Store Connect metadata** — description, subtitle, keywords,
   support URL; privacy nutrition label is simply **"Data Not Collected"**
   (the manifest backs it up); age rating 4+.
6. **Screenshots** — 6.9" iPhone and 13" iPad sets; capture the thread
   mid-stream, the zoom moment, a project dossier, the constellation, and
   the privacy receipt.

## Known gaps to close before flipping to "Ready for Sale"

- **Dynamic Type** — the type scale is fixed-size; map tokens to
  `relativeTo:` text styles and audit at AX sizes.
- **VoiceOver audit** — labels exist on controls; needs an end-to-end pass
  (streaming text announcements, constellation node navigation).
- **Localization** — English only; strings are not yet in a catalog.
- **Onboarding** — the welcome block teaches the grammar, but a 3-beat
  first-run sequence (privacy → talk → pull down) would land better.
- **App preview video** — the streaming reveal and the zoom are the pitch;
  30s capture once running on hardware.
